RaiseUp 개인정보처리방침

최종 수정일: 2026년 10월 14일

1. 수집하는 정보

RaiseUp은 어떠한 개인 정보도 수집하지 않습니다. 운동 기록(세션, 세트, 횟수, 무게)은 사용자의 기기에만 저장되며 외부 서버로 전송되지 않습니다.

2. 선택적 API 키

사용자가 직접 입력한 Claude API 키 및 ElevenLabs API 키는 기기의 UserDefaults에만 저장됩니다. 해당 키는 각 서비스(Anthropic, ElevenLabs)와의 직접 통신에만 사용되며, 앱 개발자는 이 키에 접근할 수 없습니다.

3. 오디오

앱은 운동 횟수를 음성으로 읽어주기 위해 기기의 스피커(AVSpeechSynthesizer)를 사용합니다. 마이크를 사용하지 않으며, 오디오를 녹음하거나 저장하지 않습니다.

4. 제3자 공유

사용자 데이터를 제3자와 공유하지 않습니다.

5. 어린이 개인정보

본 앱은 만 13세 미만 어린이를 대상으로 하지 않으며, 어린이의 개인 정보를 의도적으로 수집하지 않습니다.
